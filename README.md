## Projects

**🌍 African Gig-Economy & Digital Wallet Risk — Fraud & Data Quality Analysis**
Given a fraud-analysis brief listing several "expected" risk patterns, I tested each one against the actual 50,000-transaction dataset instead of taking them at face value. Initial validation found weak or inconsistent relationships between several expected risk indicators and the observed fraud, dispute, and reversal flags — for example, a transaction explicitly labeled "Reversed" shows `is_reversed = True` only 50.47% of the time. Currently finalizing the write-up on data reliability before further modeling.
`SQL · Python (Pandas, SciPy) · Matplotlib/Seaborn · Power BI` → [View project](https://github.com/jaya-harshitha-muthaknai/gig-economy-wallet-risk-analysis)

**🏦 Zephyr Bank — Transaction Health & Fraud Analytics**
Defined business requirements, documented functional requirements and a full traceability matrix, then analyzed transaction and fraud patterns using SQL, Python, and Power BI on a simulated UK fintech dataset — covering fraud concentration by segment and region, revenue leakage (expected vs. actual fees), and customer/merchant risk exposure. Delivered as an executive-facing Power BI dashboard backed by full BRD, FRD, and RTM documentation.
`SQL · Python · Power BI · Excel` → [View project](https://github.com/jaya-harshitha-muthaknai/Zephyr-Bank-Transaction-Health-Analysis)

**📊 Crowdfunding Platform — Conversion Funnel & Data Integrity Analysis**
The obvious explanation was user acquisition. It wasn't. The real bottleneck was conversion — only ~15% of users completed onboarding, and verified users were far more likely to invest. Traced the friction back to backend data integrity issues (stale OTP states, inconsistent user-state transitions) and built a Power BI dashboard to surface the funnel risk to stakeholders.
`Python (Pandas) · SQL · Power BI · Jupyter` → [View project](https://github.com/jaya-harshitha-muthaknai/crowdfunding-funnel-analysis)

**📱 Groww App — User Feedback & Product Prioritization**
