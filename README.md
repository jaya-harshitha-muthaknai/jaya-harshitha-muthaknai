## Featured Work

### 🌍 African Gig-Economy & Digital Wallet Risk — Data Quality Investigation *(in progress)*
Given a fraud-analysis brief listing six "expected" risk patterns, I'm testing each one against the actual 50,000-transaction dataset instead of assuming they're true. So far, none have held up — a chi-square test and internal consistency check show the fraud/dispute/reversal flags are statistically indistinguishable from random noise (a transaction explicitly labeled "Reversed" shows `is_reversed = True` only 50.47% of the time). Currently finalizing the writeup on whether the data is reliable enough to model on.

**Tools:** SQL · Python (Pandas, SciPy) · Matplotlib/Seaborn, Power Bi
🔗 [View project](https://github.com/jaya-harshitha-muthaknai/gig-economy-wallet-risk-analysis)

### 📊 Crowdfunding Platform — Funnel & Data Integrity Analysis
Diagnosed why a crowdfunding platform's real bottleneck wasn't user acquisition but conversion: only ~15% of users completed onboarding, and verified users were far more likely to invest. Traced the friction to backend data integrity issues (stale OTP states, inconsistent user-state transitions) and built a Power BI dashboard to track the funnel and surface the risk to stakeholders.

**Tools:** Python (Pandas) · SQL · Power BI · Jupyter
🔗 [View project](https://github.com/jaya-harshitha-muthaknai/crowdfunding-funnel-analysis)
